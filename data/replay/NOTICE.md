# Third-party data notice: traffic replay set

`replay-v1.jsonl` redistributes text from the public datasets below, after cleaning (CRLF to LF, whitespace
strip), duplicate removal and relabeling. Each record's `source` and `source_label` fields name its origin
and its original field values. Records with `source: replay_email` were generated by
`training/replay_emails.py`, and records with `source: sandbox_dev` are email bodies from this repository's
`fixtures/scenarios/dev/` (Agent C's dev scenarios). Licenses were read from each dataset card at the pinned
revision on 2026-10-29; file sha256 values are pinned in `training/replay.py` and in `MANIFEST.json`.

Apache-2.0 section 4(d): `CohereLabs/aya_dataset` ships no NOTICE file at the pinned revision (repository
files: `.gitattributes`, `README.md`, `aya_header.png`, `data/`, `demographics/`). None of the three MIT
repositories ships a LICENSE or NOTICE file (checked with the HF tree API at each revision).

Content warnings from the cards: the in-the-wild repository "contains examples of harmful language" and is
"intended for research purposes only", and its prompts were collected online and "can contain personal
information". mosscap and gandalf prompts are game submissions; the mosscap card says many are not real
injections, so mosscap items carry `label: null`.

Not checked: whether Stage 2 (`protectai/deberta-v3-base-prompt-injection-v2`) trained on any of these sources
(`stage2_overlap: unknown` in `MANIFEST.json`). The replay set is for systems measurements, not accuracy claims.
